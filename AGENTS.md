# AGENTS — вход для нового агента

1. Сначала прочитай `architecture/` (весь каталог).
2. Затем `docs/handoff.md` — тема курса, датасет, статусы, известные ловушки.
3. Исходный R&D-код живёт в соседнем репо Crazyflie (не копировать целиком):
   - `/data/projects/crazyflie/tinyml_demo/`
4. Этот репозиторий (`~/mlops`) — учебный/курсовой контур MLOps: формулировки, пайплайн, отчёты, воспроизводимые рецепты. Не смешивать с прошивкой GAP8/AI-deck, если задача явно не про edge.

## Цель курса
End-to-end MLOps для детекции дорожных знаков на базе Mapillary MTSD → обучение → метрики/гейты → экспорт → (опционально) live-проверка.

## Что не делать без запроса
- Не коммитить тяжёлые веса/датасеты в git.
- Не переписывать весь `tinyml_demo`; переносить только нужные скрипты/контракты.
- Не считать SoftAP Himax (grayscale) эквивалентом RGB MTSD — см. domain gap в handoff.
